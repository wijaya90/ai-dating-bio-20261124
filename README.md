## The entry

> Trained on a billion conversations, and somehow I'm still the one getting left on read.

## How it works

`main.ts` (Node 22, no dependencies) writes the single-line bio — 87
characters, no trailing newline — to `/output/entry.txt`. No network, no
secrets, no external files: everything the entry runs is in this repository.

Run locally:

```sh
node main.ts
```
